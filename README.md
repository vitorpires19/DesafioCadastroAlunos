
# Desafio Cadastro de Alunos — EBAC

Projeto desenvolvido como atividade prática do curso
de Desenvolvimento Back-end Java da EBAC.

## Objetivo

Criar um sistema de registro de notas escolares
utilizando Programação Orientada a Objetos, vetores
e validação de dados.

## Funcionalidades

- Cadastro de múltiplos alunos pelo console
- Classe Aluno seguindo o padrão POJO
- Atributos privados, getters e setters
- Construtor com parâmetros
- Armazenamento dos alunos em um vetor
- Armazenamento das notas em vetores
- Validação de notas entre 0 e 10
- Cálculo e exibição da média de cada aluno

## Estrutura

- `src/Aluno.java`: representa os dados do aluno
  e calcula sua média.
- `src/CadastroAlunos.java`: executa o cadastro
  e a apresentação dos resultados.

## Tecnologias

- Java 17+
- IntelliJ IDEA

## Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Acesse `src/CadastroAlunos.java`.
3. Execute o método `main()`.
4. Informe a quantidade de alunos.
5. Cadastre os nomes e as notas.
6. Confira o resumo final no console.
